# INSTRUMENT.DAQ

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery, and the [SDK](Documentation/%F0%9F%A7%A9Manual%20and%20Artifacts/SDK.md).

The **DAQ** instruments of the APK.audio bench, as one thing: 4 models, their command tables and the family's panel. Data acquisition and switch units: many inputs scanned into readings.

| | |
|---|---|
| **Is** | **inputs** — takes signals in — its connectors are inputs a patch can land on<br>**metering** — measures — its readings are numbers with units |
| **Inputs** | each model's BIM part: /api/bim/parts?full=1&id=<part> — ports where side is "input" and domain is not "power" |
| **Recipe** | none — data, not a container: read in place by the stacks that bake `INSTRUMENTS` |
| **Source** | this repository (https://github.com/LikeDotAudio/APK.plugin.instruments.VISA.DAQ.git), a submodule of [APK.plugin.instruments.VISA](https://github.com/LikeDotAudio/APK.plugin.instruments.VISA) at `INSTRUMENT.DAQ/` |
| **Family name** | `DAQ` — the device type, the topic segment and the `manifest.json` key; the `INSTRUMENT.` prefix belongs to the folder only |
